# SQL Practice: Creating and Modifying Data

For this activity, you will practice creating tables, importing data, inserting rows, updating data, deleting data, and using queries to insert or modify data.

You will use **TYSQL.sqlite** and the provided **product_reviews.csv** file.

---

## Part 1: Create and Import a Table

### 1. Create `ProductReviews`

Create a table called `ProductReviews` that can store the data in `product_reviews.csv`.

Use the following requirements:

- `review_id` is an `INTEGER` primary key.
- `prod_id` is `TEXT` and cannot be `NULL`.
- `rating` is an `INTEGER` and cannot be `NULL`.
- `reviewer` is `TEXT` and has a default value of `"Anonymous"`.
- `review_text` is `TEXT`.
- `prod_id` is a foreign key that references `Products(prod_id)`.

### 2. Import the CSV

Import `product_reviews.csv` into the `ProductReviews` table.

Then, write a query to verify that all rows were imported correctly.

## Part 2: INSERT

### 3. Insert a complete row

| Attribute | Value |

### 4. Insert a partial row

Insert another review with:

- `review_id = 10`

After inserting the row, look at the result.

**What value does `reviewer` receive? Why?**

### 5. Test the primary key

```sql

```

**What happens? Why?**
